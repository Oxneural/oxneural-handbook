# Security Policy

This repository contains documentation only. It holds no application code, credentials or client data.

## Reporting

For security issues in any OxNeural repository, follow the organization security policy: [`.github/SECURITY.md`](https://github.com/Oxneural/.github/blob/main/SECURITY.md).

**Do not open a public issue for a security vulnerability.**

## If you find a problem in these standards

If you believe a standard documented here is itself insecure — it recommends a weak practice, or omits something important — that is worth reporting too. Open a normal issue or pull request for it; it is not a vulnerability, and discussing it in the open is useful.

See [`docs/standards/security-standard.md`](docs/standards/security-standard.md).

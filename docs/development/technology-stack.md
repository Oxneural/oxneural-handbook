## Not confirmed

The following are **not** in-house capability and must never be presented as such: React, Angular, Vue, MERN, Node.js, PHP, WordPress, Flutter, native mobile, .NET, Java, Go, Rust, Kubernetes, advanced UI/UX design.

If a prospect asks for one of these:

1. Say plainly that it is not in-house.
2. If a partner or external specialist could deliver it, label it **Partner / External Capability** and price it as such.
3. If the team wants to add it, it becomes in-house only after someone has actually built and shipped something with it — not after a course.

Adding a technology to this list requires a pull request and the founder's approval. The PR must name the project where it was used.
